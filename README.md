# Mod Compat

Client-side compatibility addon for **Minecraft 1.21.1 / NeoForge 21.1.x**.

## Integrations

- **Swivel + Spatial GUI** — hides the Orbit Camera crosshair in 3D interfaces.
- **Swivel + Interactic Renewed** — fixes aiming and one-click pickup of dropped items with Orbit Camera.

## Supported versions

- Swivel: `1.2.0+mc1.21-1.21.1`
- Interactic Renewed: `0.2.3+1.21.1`
- Spatial GUI: `1.11.1-hotfix+1.21.1`

## Installation

Place `Mod-Compat-NeoForge-1.21.1-1.0.0.jar` in your client's `mods` folder. Install only the original mods whose integrations you need.

## Build

Requires **Java 21**. Run on Windows:

```powershell
.\gradlew.bat clean build
```

Output: `build/libs/Mod-Compat-NeoForge-1.21.1-1.0.0.jar`

# Mod Compat (Русский)

Клиентский аддон совместимости для **Minecraft 1.21.1 / NeoForge 21.1.x**.

## Интеграции

- **Swivel + Spatial GUI** — скрывает прицел Orbit Camera в 3D-интерфейсах.
- **Swivel + Interactic Renewed** — исправляет наведение и подбор выброшенных предметов одним нажатием ПКМ при использовании Orbit Camera.

## Поддерживаемые версии

- Swivel: `1.2.0+mc1.21-1.21.1`
- Interactic Renewed: `0.2.3+1.21.1`
- Spatial GUI: `1.11.1-hotfix+1.21.1`

## Установка

Помести `Mod-Compat-NeoForge-1.21.1-1.0.0.jar` в папку `mods` клиента. Устанавливай только те исходные моды, интеграции с которыми тебе нужны.

## Сборка

Требуется **Java 21**. В Windows выполни:

```powershell
.\gradlew.bat clean build
```

Готовый файл: `build/libs/Mod-Compat-NeoForge-1.21.1-1.0.0.jar`
